# ParkLink Deep Site

Professional multi-page ParkLink website built with Vite + React.

## Pages
- `/` Home
- `/problem`
- `/modules`
- `/app`
- `/cost`
- `/reservations`
- `/verification`
- `/future`
- `/contact`

## Deploy on Vercel
Framework: Vite  
Install: `npm install`  
Build: `npm run build`  
Output: `dist`

Upload the extracted files directly to GitHub, not the zip.
